Experiment records live here: EXP-<YYYYMMDD>-<hypothesis-id>-<slug>.md
See RESEARCH.md "Experiment tracking" for the required fields.

Pre-registrations (frozen before any result is computed, per RESEARCH.md
"Standard experiment protocol" steps 1-4) are named
PREREG-<YYYYMMDD>-<hypothesis-id>-<slug>.md. A pre-registration is never
rewritten once frozen; if an ambiguity is found before execution, add a
dated, versioned AMENDMENT-<YYYYMMDD>-<hypothesis-id>-<slug>.md that
resolves it by addition and add a visible pointer at the top of the
original document -- the same discipline RESEARCH.md already applies to
research plans and settlement labels. An experiment manifest template
(TEMPLATE-<hypothesis-id>-manifest.json) accompanies a pre-registration
when the eventual results record needs a fixed schema pinned in advance.
